# Вопрос 1. Тема: Сложные запросы
  
**1. Какой оператор используется для объединения двух таблиц в SQL?**
  
Варианты ответов:
1) UNION
2) COMBINE
3) ✅ JOIN
4) MERGE
  
### ИИ анализ
Оператор `JOIN` является основным для объединения строк из двух или более таблиц на основе связанного столбца между ними.  Опции UNION, COMBINE и MERGE либо выполняют другие операции (объединение наборов результатов), либо не являются стандартными SQL-операторами.  Ваш выбор верен, так как JOIN — это ключевое слово для горизонтального объединения таблиц по условию.  

# Вопрос 2. Тема: Сложные запросы
  
**2. Как объединить таблицы Customers и Orders по полю CustomerID и выбрать все строки из таблицы Customers, даже если нет соответствующих записей в таблице Orders?**
  
Варианты ответов:
1) SELECT * FROM Customers INNER JOIN Orders ON Customers.CustomerID = Orders.CustomerID
2) SELECT * FROM Customers RIGHT JOIN Orders ON Customers.CustomerID = Orders.CustomerID
3) SELECT * FROM Customers FULL JOIN Orders ON Customers.CustomerID = Orders.CustomerID
4) ✅ SELECT * FROM Customers LEFT JOIN Orders ON Customers.CustomerID = Orders.CustomerID
  
### ИИ анализ
`LEFT JOIN` возвращает все записи из левой таблицы (Customers) и соответствующие записи из правой (Orders).  Если соответствия нет, результат для правой таблицы будет содержать NULL.  INNER JOIN вернёт только совпадающие строки, а RIGHT JOIN вернул бы все заказы, даже без клиентов.  Ваш ответ правильный, он точно соответствует условию задачи.  

# Вопрос 3. Тема: Сложные запросы
  
**3. Что вернёт запрос `SELECT Customers.Name, Orders.OrderID FROM Customers LEFT JOIN Orders ON Customers.CustomerID = Orders.CustomerID;`, если в таблице Customers есть клиенты без заказов?**
  
Варианты ответов:
1) ✅ Запрос вернёт всех клиентов (включая тех, у кого нет заказов) с пустыми значениями для OrderID
2) Запрос вернёт только клиентов с заказами
3) Запрос вернёт только заказы, без клиентов
4) Запрос не вернёт результатов
  
### ИИ анализ
Поскольку используется `LEFT JOIN`, результатом будут все строки из таблицы Customers.  Для клиентов, у которых есть заказы, будут указаны их OrderID.  Для клиентов без заказов в столбце OrderID будет значение NULL (отображаемое как пустое).  Вы правильно поняли логику работы LEFT JOIN.  

# Вопрос 4. Тема: Сложные запросы
  
**4. Какой результат вернёт следующий SQL-запрос?**

```
SELECT Name FROM Customers
UNION
SELECT Name FROM Suppliers;
```
  
Варианты ответов:
1) Вернёт только совпадающие значения из обеих таблиц
2) ❌ Объединит результаты обеих таблиц, включая дубликаты
3) Вернёт только уникальные имена из таблиц Customers и Suppliers
4) Объединит результаты, но добавит NULL вместо отсутствующих значений
  
### ИИ анализ
Оператор `UNION` по умолчанию объединяет результаты двух запросов, автоматически удаляя все дублирующиеся строки.  Ваш выбранный вариант неверен, так как он утверждает, что дубликаты будут включены (для этого нужен UNION ALL).  Правильный ответ — вариант 3: запрос вернёт один список уникальных имён из обеих таблиц.  

# Вопрос 5. Тема: Сложные запросы
  
**5. Какой результат вернёт следующий SQL-запрос?**

```
SELECT ProductName FROM Products
EXCEPT
SELECT ProductName FROM DiscontinuedProducts;
```
  
Варианты ответов:
1) Вернёт только товары, которые присутствуют в обеих таблицах
2) Вернёт список всех товаров, включая устаревшие
3) ❌ Вернёт только устаревшие товары
4) Вернёт товары, которые есть в Products, но отсутствуют в DiscontinuedProducts
  
### ИИ анализ
Оператор `EXCEPT` возвращает строки из первого набора данных, которые отсутствуют во втором.  В данном контексте это означает выборку товаров, которые есть в таблице Products, но которых нет в таблице DiscontinuedProducts, то есть текущих, не снятых с производства товаров.  Ваш выбор неверен, так как он описывает противоположную операцию.  Правильный ответ — вариант 4.
