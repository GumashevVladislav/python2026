# Вопрос 17. Тема 3: Рекурсия

Варианты ответов:
1) Станет быстрее
2) ❌ Выполнится один раз
3) Будет ошибка RecursionError
4) Создаст файл

# Вопрос 37. Тема 6: Основы асинхронного программирования

Выбранный вариант "Для списков" неверен, так как работа со списками — это операция в памяти, не требующая асинхронности.  Для вычислений (CPU-bound) `asyncio` не дает преимуществ.

# Вопрос 38. Тема 6: Основы асинхронного программирования

Как объявить асинхронную функцию в Python?

Варианты ответов:
1) def async f():
2) async function f():
3) ❌ def f() async:
4) await def f():
5) async def f():

### ИИ анализ
Синтаксис объявления асинхронной функции в Python строго определен: ключевое слово `async` ставится перед `def`.  Выбранный вариант `def f() async:` нарушает этот порядок и является недопустимым.  Правильный синтаксис `async def f():` создает корутину — специальный объект, который можно запускать с помощью `await` или `asyncio.run`.

# Вопрос 39. Тема 6: Основы асинхронного программирования

Что делает await?

Варианты ответов:
1) Завершает программу
2) Импортирует модуль
3) ✅ Ожидает завершения асинхронной операции
4) Создает список
5) Печатает результат

### ИИ анализ
Ключевое слово `await` приостанавливает выполнение текущей асинхронной функции до тех пор, пока не завершится ожидаемая асинхронная операция (корутина, задача, future).  Во время этой паузы управление передается другим задачам в цикле событий, что и позволяет достичь конкурентности.  Оно не завершает программу и не выполняет операции ввода-вывода напрямую.

# Вопрос 40. Тема 6: Основы асинхронного программирования

Это фундаментальная единица выполнения в асинхронном программировании на Python, а не тип данных или ошибка.  Понимание этого термина критически важно для работы с `asyncio`.

# Вопрос 42. Тема 6: Основы асинхронное программирование

Это отличается от параллелизма с использованием потоков или процессов.  Ключевая идея — эффективное использование времени простоя одной задачи для работы другой.

### ИИ анализ

# Вопрос 47. Тема 7: SQL, база и многотабличные запросы

3) Два случайных числа
