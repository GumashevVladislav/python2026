## Блок 2. Каркас HTML и семантика

### Содержание и вопросы

- Что такое базовая структура HTML-документа?
- Зачем нужны `head` и `body`?
- Какие семантические теги подходят для шапки, основного контента и подвала?
- Как правильно использовать заголовки `h1`-`h3`?

### Материал (лаконично)

- `<!doctype html>` это “режим HTML”. Без него браузер может странно интерпретировать разметку.
- `head` это “настройки страницы”:
  - кодировка, чтобы текст на русском не ломался
  - `viewport`, чтобы страница нормально выглядела на телефоне
  - `title`, чтобы было понятное имя вкладки
  - подключение `styles.css`
- `body` это все, что видит пользователь.
- Семантические теги это понятные названия блоков вместо безликих контейнеров. Они помогают:
  - быстрее ориентироваться в коде
  - лучше понимать структуру страницы
  - подготовить основу для доступности
- Минимальный набор для страницы-визитки: `header` (шапка), `main` (основное), `footer` (подвал).
- Заголовки:
  - `h1` один на страницу, это главный смысл страницы
  - `h2` для секций
  - `h3` для элементов внутри секции, например для карточек

Это не вопрос на проверку знаний, а подтверждение ознакомления с материалом. Ответ "Прочитано" означает, что студент изучил предоставленные инструкции и правила. # Вопрос 3. Где находится весь контент, который видит пользователь на странице (текст, картинки, ссылки)?
  
  
Варианты ответов:
1) ✅ Внутри `body`
2) Внутри `head`
3) Внутри `link`
4) Внутри `meta`
5) Внутри `title`
  
### ИИ анализ
Правильный ответ — внутри `body`. Тег `<body>` содержит всё видимое содержимое веб-страницы: текст, изображения, ссылки, видео и другие элементы. Тег `<head>`, напротив, содержит метаинформацию для браузера и поисковых систем, которая не отображается напрямую на странице.  

# Вопрос 4. Для чего нужен мета-тег `viewport`, чтобы страница нормально выглядела на мобильных телефонах?
  
  
Варианты ответов:
1) Для включения JavaScript
2) Для вставки картинки
3) Для настройки шрифтов
4) ✅ Для нормального вида на телефоне
5) Для создания списка
  
### ИИ анализ
Мета-тег `viewport` управляет макетом и масштабированием страницы на мобильных устройствах. Без него браузер может отображать страницу как на десктопе, заставляя пользователя масштабировать её вручную. Правильная настройка `viewport` обеспечивает адаптивное отображение контента под ширину экрана устройства.  

# Вопрос 5. Какие семантические теги лучше использовать для создания основной структуры страницы-визитки (шапка, основной контент, подвал)?
  
  
Варианты ответов:
1) ✅ `header`, `main`, `footer`
2) `table`, `tr`, `td`
3) `b`, `i`, `u`
4) `form`, `input`, `button`
5) `script`, `style`, `link`
  
### ИИ анализ
Семантические теги `header`, `main` и `footer` точно описывают назначение основных разделов страницы, улучшая читаемость кода и доступность. Альтернативы, такие как таблицы (`table`) или теги форматирования (`b`, `i`), не предназначены для создания основной структуры страницы и являются устаревшим или неправильным подходом.

# Вопрос 7. Почему семантические теги (например, `header`, `main`, `footer`) лучше обычных `div` для структуры страницы?
  
  
Варианты ответов:
1) Чтобы заменить CSS
2) ✅ Чтобы структура была понятнее
3) Чтобы скрыть контент
4) Чтобы ускорить интернет
5) Чтобы отключить отступы
  
### ИИ анализ
Семантические теги придают смысловое значение блокам кода, делая структуру понятнее для разработчиков, браузеров, скринридеров и поисковых систем. В отличие от универсального `<div>`, они явно указывают на роль раздела (например, шапка, основное содержание), что улучшает доступность и SEO.  

# Вопрос 8. В каком месте HTML-документа правильно подключать CSS-файл через тег `link`?
  
  
Варианты ответов:
1) ❌ В `body` после `footer`
2) В `head` через `link`
3) Внутри `meta charset`
4) Внутри `title` страницы
5) Внутри комментария
  
### ИИ анализ
Тег `<link>` для подключения CSS должен находиться внутри раздела `<head>` документа. Это гарантирует, что стили загрузятся до отображения содержимого `<body>`, предотвращая мерцание нестилизованного контента. Размещение в `<body>` не является стандартным и может привести к проблемам с производительностью.
