# Вопрос 1. Тема: Основы SQL
  
**1. Какая команда используется для извлечения всех записей из таблицы в SQL?**
  
Варианты ответов:
1) SELECT all FROM table_name;
2) SELECT 1 FROM table_name;
3) ✅ SELECT * FROM table_name;
4) SELECT FROM table_name;
  
### ИИ анализ
Команда `SELECT * FROM table_name;` является стандартным синтаксисом SQL для выбора всех столбцов из указанной таблицы.  Символ `*` — это специальный метасимвол, обозначающий "все столбцы".  Другие варианты либо используют несуществующий синтаксис, либо выбирают конкретные значения, а не все записи.  

# Вопрос 2. Тема: Основы SQL
  
**2. Как ограничить выборку по конкретному условию?**
  
Варианты ответов:
1) ❌ SELECT * FROM table_name ORDER BY condition;
2) SELECT WHERE condition FROM table_name;
3) SELECT * WHERE condition FROM table_name;
4) SELECT * FROM table_name WHERE condition;
  
### ИИ анализ
Для фильтрации записей по условию в SQL используется ключевое слово `WHERE`.  Правильный синтаксис требует, чтобы предложение `WHERE` следовало сразу после `FROM table_name`.  Выбранный вариант (1) использует `ORDER BY`, который предназначен для сортировки, а не для фильтрации, поэтому он неверен.  

# Вопрос 3. Тема: Основы SQL
  
**3. Как отсортировать результаты по убыванию значения в столбце age?**
  
Варианты ответов:
1) SELECT * ORDER BY age FROM table_name;
2) SELECT * FROM table_name ORDER BY DESC age;
3) SELECT * FROM table_name WHERE age ORDER BY DESC;
4) ✅ SELECT * FROM table_name ORDER BY age DESC;
  
### ИИ анализ
Правильный ответ демонстрирует корректный порядок предложений в SQL: сначала `FROM`, затем `ORDER BY`.  Ключевое слово `DESC` (означающее "по убыванию") должно следовать сразу после имени столбца, по которому происходит сортировка.  Другие варианты нарушают этот синтаксический порядок.  

# Вопрос 4. Тема: Основы SQL
  
**4. Как выбрать записи, где age меньше 30 или salary больше 50000, и отсортировать их по name?**
  
Варианты ответов:
1) SELECT * FROM table_name ORDER BY age < 30 OR salary > 50000, name;
2) SELECT * FROM table_name WHERE age < 30 OR salary > 50000 ORDER BY name;
3) ❌ SELECT * FROM table_name WHERE age < 30 OR salary > 50000 name;
4) SELECT * FROM table_name WHERE age < 30 AND salary > 50000 ORDER BY name;
  
### ИИ анализ
Выбранный вариант (3) содержит синтаксическую ошибку: отсутствует ключевое слово `ORDER BY` перед `name`.  Правильный вариант (2) корректно использует `WHERE` для фильтрации по условию с оператором `OR` и `ORDER BY` для сортировки результатов.  Условие `AND` (вариант 4) изменило бы логику запроса.  

# Вопрос 5. Тема: Основы SQL
  
**5. Как выбрать записи, где salary больше 50000 и age больше 25?**
  
Варианты ответов:
1) SELECT * FROM table_name WHERE salary > 30000, age > 25;
2) SELECT * FROM table_name WHERE salary > 30000 NOT age > 25;
3) SELECT * FROM table_name WHERE salary > 30000 OR age > 25;
4) ✅ SELECT * FROM table_name WHERE salary > 30000 AND age > 25;
  
### ИИ анализ
Для одновременного выполнения двух условий в SQL используется логический оператор `AND`.  Выбранный правильный вариант (4) корректно фильтрует записи, где оба условия истинны.  Оператор `OR` (вариант 3) вернул бы записи, удовлетворяющие хотя бы одному условию, что не соответствует требованию задачи.
